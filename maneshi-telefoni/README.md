# منشی تلفنی میراث ملک

این پوشه مخصوص منشی تلفنی است و با سامانه مدیریت فایل املاک یکی نیست.

## هدف
- دریافت شماره مشتری
- آغاز تماس
- پرسش مشخصات ملک
- آماده‌سازی برای اتصال موتور گفتار/هوش مصنوعی

نکته: تماس تلفنی هوشمند واقعی نیازمند سرویس VoIP/Telephony و کلیدهای سرویس است؛ این اطلاعات نباید داخل APK قرار گیرد.
